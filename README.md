# Module-2---Back-Account-Simulator
 
## Description
A Bank Account similation build with Java including features such as withdraw, deposit, balance view, and other classic features based on the real functioning of an electronic bank account.

## Getting Started
1. Download the repository files.
2. Open project file with Intellij IDE or another Java editors
3. run the Main.java file
